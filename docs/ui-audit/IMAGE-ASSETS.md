# ContaPro — imagem original

## Asset integrado
`public/images/contapro/auth/login-finance.webp`: ilustração original gerada com ImageGen, 960 × 640, 22.988 bytes. Integrada ao painel desktop de `GuestLayout.vue`, usado pelas páginas de autenticação. Dimensões explícitas, decoding async, loading lazy e alt vazio porque é decorativa. No mobile, o painel é ocultado para priorizar o formulário.

Conceito: organização financeira pessoal por folhas e volumes abstratos em papel, progressão de degraus e arco, fundo azul-marinho, formas marfim, azul cobalto e pequeno toque verde. Sem pessoas, marcas externas, cifras, números ou rentabilidade sugerida. A imagem não representa dados do usuário.

Direção de geração: ilustração editorial em 3D de papel fosco, composição horizontal 3:2, folhas de livro-caixa sobrepostas, volumes em degraus e arco circular, luz suave, espaço negativo, paleta off-white/cobalt/navy/sage. Sem texto, logotipo, moedas ou gráficos numéricos. Otimização via Sharp para WebP.

O original de geração permanece na biblioteca local do Codex. A cópia PNG intermediária foi removida do projeto após a otimização; o produto distribui apenas o WebP. Não havia imagem de marca de produto substituída: marca em código e favicon preservados. Blobs/gradientes decorativos foram removidos dos layouts. Não foram geradas imagens adicionais para dados, gráficos ou vazios: componentes e ícones existentes cumprem melhor essa função.
